# KPI Design and BI Fundamentals 📈

Este proyecto corresponde al **Sprint 7** del itinerario de **Análisis de Datos**. En este bloque, doy el salto de las bases de datos puras a la **Inteligencia de Negocio (BI)**, transformando datos transaccionales en un cuadro de mando interactivo y visual en **Power BI**.

## 🎯 Objetivos y Logros Técnicos

### 1. Modelado de Datos para BI
He importado y validado el ecosistema de datos (basado en el modelo de transacciones de Sprints anteriores) asegurando que las relaciones entre tablas sean óptimas para el reporte:
* **Integridad del Modelo**: Verificación de las relaciones de cardinalidad para evitar ambigüedades en los cálculos.
* **Preparación del Entorno**: Resolución de retos técnicos de infraestructura, utilizando virtualización para ejecutar Power BI Desktop en un entorno macOS (Apple Silicon).

### 2. Diseño de Indicadores Clave (KPIs)
He definido y calculado métricas críticas para la monitorización del negocio:
* **Ticket Promedio**: Cálculo de la media de gasto por transacción para entender el valor del cliente.
* **Análisis vs. Objetivo**: Implementación de indicadores visuales para comparar el Ticket Promedio real frente al objetivo de negocio (fijado en $260).
* **Frecuencia y Variedad**: Análisis de la cantidad de productos únicos comprados por cliente para identificar patrones de fidelización.

### 3. Visualización y Storytelling de Datos
El foco principal fue la **legibilidad** y la selección del gráfico adecuado para cada historia:
* **Análisis Geográfico**: Uso de mapas interactivos para localizar la procedencia de los usuarios y detectar mercados clave.
* **Perfiles de Compra**: Visualización de extremos de gasto y productos favoritos por cliente.
* **UX/UI en Reportes**: Mejora de la claridad mediante títulos descriptivos, limpieza de ejes y una jerarquía visual que facilita la toma de decisiones.

## 🛠️ Stack Tecnológico
* **Herramienta BI**: Power BI Desktop.
* **Virtualización**: UTM / Parallels (para ejecución en Mac M1).
* **Conceptos clave**: KPIs, Análisis de Tendencias, Data Storytelling y Georreferenciación.
