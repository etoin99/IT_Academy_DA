# Python Programming Core for Data 🐍

Este repositorio recoge los fundamentos de programación en **Python** aplicados al **Análisis de Datos** (Sprint 9). Aquí el enfoque no es solo la herramienta, sino la construcción de algoritmos eficientes, el control de flujo y la gestión de estructuras de datos esenciales.

## 🚀 Competencias Desarrolladas

### 1. Programación Funcional y Lógica
En el notebook principal (`Tasca S9.01`), he desarrollado una serie de programas diseñados para facilitar procesos cotidianos mediante:
* **Creación de Funciones**: Definición de bloques de código reutilizables con parámetros y retornos precisos.
* **Conversión de Unidades**: Implementación de un conversor de temperaturas multiescala (Celsius, Fahrenheit, Kelvin, etc.) basado en una matriz de conversión lógica.

### 2. Estructuras de Datos y Bucles
* **Manipulación de Colecciones**: Uso intensivo de listas, diccionarios y tuplas para organizar información compleja.
* **Control de Flujo**: Aplicación de bucles `for` y `while` combinados con estructuras condicionales `if-elif-else` para procesar datos de forma iterativa.

### 3. Procesamiento de Archivos y Texto
Utilizando archivos como `historic_partits.txt` y `tu_me_quieres_blanca.txt`, he practicado técnicas de:
* **Lectura de Archivos**: Apertura y cierre de flujos de datos externos.
* **Análisis de Texto**: Limpieza de strings, conteo de frecuencias y extracción de patrones de texto (parsing), habilidades críticas para la fase de limpieza en cualquier proyecto de datos.


## 🛠️ Herramientas Utilizadas
* **Python 3.x**: El lenguaje core del proyecto.
* **Datetime**: Para la gestión de sellos temporales en los reportes de salida.
* **Estructuras de Control**: Lógica pura para la automatización de tareas.
